Keuda's official font is Titillium Web (brand book p. 8).

Add these three files to this folder and the site uses them automatically:

  TitilliumWeb-Regular.woff2
  TitilliumWeb-SemiBold.woff2
  TitilliumWeb-Bold.woff2

Titillium Web is free (SIL Open Font License) and can be downloaded from
Google Fonts. Self-hosting the files here avoids loading anything from
Google when students open the site.

Until the files are added the browser shows Arial, the brand book's fallback.
