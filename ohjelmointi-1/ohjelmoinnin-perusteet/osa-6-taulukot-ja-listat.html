Osa 6: Taulukot ja listat

Taulukoihin ja listoihin voi tallentaa useita saman tyyppisiä arvoja yhteen paikkaan.

Array-taulukko

Array-taulukon edut

  • Käytön helppous: taulukot mahdollistavat useiden arvojen tallentamisen yhteen paikkaan.
  • Suorituskyky: taulukot ovat tehokkaita, koska ne tarjoavat suoran pääsyn elementteihin indeksin avulla.
  • Joustavuus: taulukkojen avulla voit helposti suorittaa toistuvia operaatioita, kuten laskentaa, lajittelua ja etsimistä.

Taulukon määrittely

int[] numerot = { 1, 2, 3, 4, 5 };

Tämä luo kokonaislukutaulukon, joka sisältää viisi elementtiä. Taulukon tyyppi on int[], mikä tarkoittaa, että se voi sisältää vain kokonaislukuja.

Taulukon indeksit

Taulukot aloitetaan aina indeksistä [0]. Indeksissä [0] oleva arvo on siis aina taulukon ensimmäinen. Alla olevassa esimerkissä taulukon indeksissä [0] oleva arvo on 5.

// Array-taulukko numeroista
int[] numeroita = { 5, 20, 12, 2, 1 };

// Tulostetaan konsoliin taulukon numerot, jotka ovat indekseissä [0] ja [2]
// [0]-indeksissä oleva tulostaa taulukon ensimmäisen numeron
// [2]-indeksissä oleva tulostaa taulukossa kolmantena olevan numeron
Console.WriteLine("Numero indeksillä [0] on " + numeroita[0]);
Console.WriteLine("Numero indeksillä [2] on " + numeroita[2]);
Numero indeksillä [0] on 5
Numero indeksillä [2] on 12

List-taulukko

Listat ovat erittäin hyödyllisiä tietorakenteita, joiden avulla voidaan tallentaa useita saman tyyppisiä arvoja. Toisin kuin taulukot (array), listat voivat kasvaa ja kutistua tarpeen mukaan. Listojen avulla voimme lisätä, poistaa ja muokata elementtejä helposti.

Yksiulotteinen lista on yksinkertainen kokoelma elementtejä, joka voi tallentaa vaikkapa kokonaislukuja, merkkijonoja tai muita arvoja.

Indeksointi alkaa nollasta

Listan ensimmäinen alkio löytyy indeksistä 0. Vaikka listassa olisi viisi alkiota, niiden indeksit ovat 0, 1, 2, 3 ja 4. Ensimmäinen alkio on siis numerolla 0, toinen numerolla 1, ja niin edelleen.

Listan perusrakenne

Yksiulotteisen listan käyttöön tarvitaan yleensä System.Collections.Generic-kirjasto, jonka kautta saamme käyttöön List<T>-tietotyypin.

using System.Collections.Generic;

List<int> numerot = new List<int> { 10, 20, 30, 40, 50 };

Listan perustoiminnot

ToimintoTarkoitus
Add(item)Lisää uuden alkion listan loppuun.
Remove(item)Poistaa ensimmäisen alkion, joka vastaa annettua arvoa.
RemoveAt(index)Poistaa alkion tietystä indeksistä.
CountPalauttaa listan alkioiden määrän.
Insert(index, item)Lisää alkion tiettyyn kohtaan listassa.

Esimerkki: luvut listassa

List<int> numerot = new List<int> { 10, 20, 30, 40, 50 };

// Käytetään laskuria alkaen 0-indeksistä
int i = 0;
while (i < numerot.Count)   // Count kertoo listan alkioiden määrän
{
    Console.WriteLine("Indeksi " + i + ": " + numerot[i]);
    i++;
}

// Tulostetaan alkioiden määrä
Console.WriteLine("Listassa on yhteensä " + numerot.Count + " alkiota.");
Indeksi 0: 10
Indeksi 1: 20
Indeksi 2: 30
Indeksi 3: 40
Indeksi 4: 50
Listassa on yhteensä 5 alkiota.

Esimerkki: alkioiden lisääminen ja poistaminen

Alla olevassa esimerkissä luodaan lista merkkijonoista, lisätään siihen arvoja ja poistetaan yksi arvo.

List<string> nimet = new List<string>();

// Lisätään nimiä listaan
nimet.Add("Anna");
nimet.Add("Mikko");
nimet.Add("Sara");

// Tulostetaan nimet
Console.WriteLine("Nimet listassa:");
int i = 0;
while (i < nimet.Count)
{
    Console.WriteLine(nimet[i]);
    i++;
}

// Poistetaan yksi nimi
nimet.Remove("Mikko");

Console.WriteLine("\nNimet listassa poiston jälkeen:");
i = 0;
while (i < nimet.Count)
{
    Console.WriteLine(nimet[i]);
    i++;
}
Nimet listassa:
Anna
Mikko
Sara

Nimet listassa poiston jälkeen:
Anna
Sara
