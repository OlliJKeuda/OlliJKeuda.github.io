Osa 2: Muuttujat ja tietotyypit

Opit tallentamaan tietoa muuttujiin, tulostamaan sitä konsoliin ja tekemään sillä laskutoimituksia.

Tietotyypit

Tietotyyppi kertoo, miten tieto tulkitaan. Tietokoneen muisti koostuu järjestyksessä olevista biteistä, ja niiden tulkinta on vapaa. Sama osa muistin sisältöä voidaan tulkita esimerkiksi merkiksi, kokonaisluvuksi, liukuluvuksi tai osoitteeksi toiseen muistipaikkaan. Tietotyypit kertovat ohjelmille ja ohjelmoijille, miten nämä bitit tulkitaan.

Yleisimmät tietotyypit C#:ssa

TyyppiKuvausEsimerkki
string Merkkijono eli teksti. Kirjoitetaan C#:ssa lainausmerkkien sisään. "Hello World"
int Kokonaisluku (integer). Arvo voi olla väliltä -2 147 483 648 ... 2 147 483 647. 42
float Reaaliluku, jolla käsitellään desimaaleja. Lopussa on pieni f-kirjain. Arvo voi olla väliltä -3,402823 × 1038 ... 3,402823 × 1038. 10.25f
double Reaaliluku kuten float, mutta suuremmille desimaaliarvoille. Arvo voi olla väliltä -1,79769313486232 × 10308 ... 1,79769313486232 × 10308. 3.1415926535

Muuttujat

Muuttuja on muistipaikka, jossa ohjelma voi säilyttää tarvitsemaansa tietoa.

  • Nimi on tunnus, jolla muuttujaan viitataan ohjelmassa. Nimessä voi olla kirjaimia ja numeroita, mutta nimi ei saa alkaa numerolla.
  • Tietotyyppi kertoo, millaista tietoa muuttujaan voi tallentaa.
  • Arvo on muuttujaan tallennettu data, jonka pitää olla tietotyypin mukainen.

Muuttujan tietotyyppiä ei voi muuttaa sovelluksen ajon aikana, mutta arvoa voi.

Muuttujan kirjoittaminen

string etunimi = "Pekka";
  1. Muuttujalle annetaan ensin tietotyyppi (string).
  2. Muuttujalle annetaan nimi. Muuttujien nimet kannattaa aina kirjoittaa pienellä alkukirjaimella. Nimeä käytetään, kun muuttujan arvoa halutaan käyttää, esimerkiksi tulostettaessa konsoliin.
  3. Lopuksi muuttujalle annetaan arvo. Nimen ja arvon väliin tulee =-merkki. Arvo on se data, jota muuttuja pitää sisällään.
  4. Lopuksi muista laittaa puolipiste ;.

Muita esimerkkejä

Sama rakenne toimii kaikille edellä käydyille tietotyypeille:

int ikä = 18;
float pituus = 180.5f;
double pii = 3.1415926535;
char merkki = 'e';
bool olenkoAktiivinen = true;

Muuttujien käyttäminen

Muuttujia voi käyttää missä tahansa logiikassa, esimerkiksi tekstin tulostamisessa konsoliin tai laskujen tekemisessä. Muuttujaa käytetään kutsumalla sen nimeä. Tämän voi tehdä esimerkiksi Console.WriteLine-toiminnolla:

string helloWorld = "Hello World!";

Console.WriteLine(helloWorld);
Hello World!

Console-luokan Write-toiminnot

Console-luokassa on kaksi tulostustoimintoa:

  • Console.WriteLine(string); tulostaa sulkujen sisään antamasi syötteen. Seuraava tulostettava asia tulee seuraavalle riville.
  • Console.Write(string); ei sisällä rivinvaihtoa. Seuraava tuloste tulostuu samalle riville kuin edellinen.

WriteLine-metodi eli toiminto ottaa parametriksi string-tyyppisen arvon. Sen sisälle voi kirjoittaa suoraan tekstiä, esimerkiksi Console.WriteLine("Hello World");, tai käyttää muuttujaa, kuten yllä Console.WriteLine(helloWorld);.

Parametri on metodille (toiminnolle, funktiolle) annettava alkuarvo, jonka perusteella se saa aikaan jonkin tuloksen. Tässä esimerkissä tulos on se, että konsoliin kirjoitetaan viesti.

Usean arvon yhdistäminen

Console.WriteLine- ja Console.Write-toimintojen sisällä voi olla useita string-arvoja, jotka erotetaan +-merkillä:

string hello = "Hello";
string world = "World";

Console.WriteLine(hello + world + "!");
HelloWorld!

Huomataan, että "Hello" ja "World" väliltä puuttuu välilyönti. Se korjataan lisäämällä muuttujien väliin tyhjä välilyönti merkkijonona:

Console.WriteLine(hello + " " + world + "!");
Hello World!

String- ja int-muuttujien yhdistäminen

Kaikki muuttujatyypit voi yhdistää merkkijonoksi Console.WriteLine-toiminnon sisällä. Ne täytyy vain erottaa +-merkillä:

string nimi = "Pekka";
int ikä = 18;

Console.WriteLine("Hei! Olen " + nimi + " ja olen " + ikä + "v");
Hei! Olen Pekka ja olen 18v

Console.Write ja Console.WriteLine

Console.Write lisää tekstin konsoliin ilman uuden rivin lisäystä eli teksti lisätään suoraan edellisen viestin perään. Console.WriteLine lisää tekstin loppuun rivinvaihdon (line terminator, newline), jolloin seuraava viesti kirjoitetaan aina omalle rivilleen.

Console.WriteLine("WriteLine. (Rivin loppu)");
Console.Write("Write.");
Console.Write("Write.");
Console.WriteLine("WriteLine.(Rivin loppu)");
Console.Write("Write.");
WriteLine. (Rivin loppu)
Write.Write.WriteLine.(Rivin loppu)
Write.

Rivinvaihto: \n

Toinen tapa saada "tyhjä" rivi tai rivinvaihto tulosteeseen on käyttää newline-koodia merkkijonon sisällä. Se on yleinen tapa lisätä tekstiin uusi rivi lähes kaikissa ohjelmointikielissä. Newline lisätään tekstiin merkinnällä \n suoraan string-merkkijonon sisään, esimerkiksi tekstin alkuun, loppuun tai keskelle:

Console.WriteLine("Ensimmäinen rivi\nToinen rivi");
Ensimmäinen rivi
Toinen rivi

Muuttujien muokkaaminen ja peruslaskutoimitukset

Muuttujilla voi tehdä peruslaskutoimituksia, ja niitä voi yhdistää toisten muuttujien arvoiksi.

Muuttujan arvon muokkaaminen

Muuttujien arvoja voi muokata sovelluksen ajon aikana. Voit vaihtaa muuttujan arvoksi jonkin toisen, yhdistää muuttujia yhteen tai käyttää muuttujiin peruslaskutoimituksia, esimerkiksi laskea kaksi int-arvoa yhteen.

Alla luodaan ensin string-muuttuja nimi, jolle annetaan arvoksi "Pekka", ja nimi tulostetaan konsoliin. Tulostuksen jälkeen muokataan jo olemassa olevaa muuttujaa ja annetaan sille uusi arvo "Jukka".

string nimi = "Pekka";

Console.WriteLine(nimi);

nimi = "Jukka";

Console.WriteLine(nimi);
Pekka
Jukka

Konsoliin tulostuu kaksi nimeä. Ne ovat saman muuttujan arvoja, joista jälkimmäinen on muokattu sovelluksen ajon aikana.

Tietotyyppiä ei kirjoiteta uudelleen

Kun muuttujan arvoa muokataan, tietotyyppiä ei enää kirjoiteta. Tietotyyppi annetaan vain silloin, kun muuttuja luodaan.

Muuttujien yhdistäminen

Useita muuttujia voi yhdistää uudeksi muuttujaksi:

string etunimi = "Pekka";
string sukunimi = "Virtanen";

string kokonimi = etunimi + " " + sukunimi;

Console.WriteLine(kokonimi);
Pekka Virtanen

Peruslaskutoimitukset

int-, float- ja muille numeerisille muuttujille voi suorittaa erilaisia laskutoimituksia. Niihin käytetään operaattoreita, jotka ovat merkkejä eri laskemis- ja yhdistämistoiminnoissa. Yksi niistä on aiemmin käytetty +-merkki, jolla yhdistettiin merkkijonoja.

OperaattoriToiminto
+Summa
-Erotus
*Kertolasku
/Jakolasku

Esimerkkejä eri laskutoimituksista int-muuttujilla:

int a = 10;              // Määritetään integer a -muuttuja
int b = 5;               // Määritetään integer b -muuttuja

int summa = a + b;       // a ja b summa -> 10 + 5 = 15
int erotus = a - b;      // a ja b erotus -> 10 - 5 = 5
int kertolasku = a * b;  // a ja b kertolasku -> 10 * 5 = 50
int jakolasku = a / b;   // a ja b jakolasku -> 10 / 5 = 2
