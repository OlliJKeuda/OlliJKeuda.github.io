Osa 5: Ikuinen silmukka

Ikuinen silmukka toistaa koodia, kunnes sen sisältä poistutaan break-komennolla.

Ikuinen silmukka

Ikuisen silmukan saa, kun while-silmukan ehdoksi laitetaan true. Ikuinen silmukka pyörii loputtomiin, ellei sitä lopeteta silmukan sisältä esimerkiksi if-ehdolla.

while (true)
{
    Console.WriteLine("weee");
}

Konsoli tulostaa loputtomiin tekstin "weee":

weee
weee
weee
weee
weee
weee
weee
weee
...
Sovellus ei lopu itsestään

Ikuista silmukkaa ajava sovellus jatkaa, kunnes suljet konsoli-ikkunan.

Silmukasta poistuminen

Silmukasta voidaan poistua aikaisemmin break;-komennolla. Sitä voidaan kutsua esimerkiksi while-silmukan sisällä olevassa if-lauseessa.

int i = 1;   // kokonaisluku silmukkaa varten

while (true)
{
    Console.WriteLine("weee");

    // Kun i:n arvo on 15, niin ehto toteutuu
    if (i == 15)
    {
        // break-komento poistaa meidät silmukasta
        break;
    }

    i++;   // Lisätään i:hin yksi
}

Nyt sovellus tulostaa sanan "weee" vain 15 kertaa. Kun i-muuttujan arvo on 15, if-lauseessa kutsutaan break;-komentoa, joka poistaa meidät silmukasta.
