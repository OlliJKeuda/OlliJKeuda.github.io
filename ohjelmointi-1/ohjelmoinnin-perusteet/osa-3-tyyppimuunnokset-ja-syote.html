Osa 3: Tyyppimuunnokset ja käyttäjän syöte

Opit muuttamaan arvon tietotyypistä toiseen ja tarkistamaan, onko käyttäjän antama syöte sitä mitä odotit.

Muita muunnostoimintoja

ToString()

.ToString()-toiminnolla muutetaan jokin tyyppi string-tyypiksi. Se onnistuu lähes kaikkien tietotyyppien kanssa.

Aiemmin mainittu sulkuoperaattori ei aina toimi, kun tyyppi halutaan muuttaa string-tyypiksi. Alla oleva koodi ei esimerkiksi onnistu:

int a = 10;

string merkkijono = (string)a;   // Ei toimi: koodi ei käänny

Käytä sen sijaan .ToString()-toimintoa, joka lisätään muuttujan nimen perään: a.ToString().

Huomaa piste

Muuttujan nimen ja ToString()-toiminnon välissä on piste.

int a = 10;

string merkkijono = a.ToString();

Convert

Convert.ToXXX-toiminnolla voidaan muuttaa perustietotyyppejä toiseksi tietotyypiksi. Esimerkiksi a voidaan muuttaa merkkijonoksi näin:

int a = 10;

string merkkijono = Convert.ToString(a);

Toiseen suuntaan, merkkijonosta kokonaisluvuksi:

string merkkijono = "123";
int luku = Convert.ToInt32(merkkijono);

Muunnos merkkijonosta kokonaisluvuksi onnistuu vain, jos merkkijonon arvo on oikeasti luku. Jos merkkijono-muuttujan arvo olisi esimerkiksi "123 a", muunnos ei onnistuisi ja konsoliin tulisi virheilmoitus:

string merkkijono = "123 a";
int luku = Convert.ToInt32(merkkijono);
Unhandled Exception: System.FormatException: Input string was not in a correct format.
   at System.Number.StringToNumber(...)
   at System.Convert.ToInt32(String value)
   ...

Parse-metodi

Tyyppien Parse- ja TryParse-metodeilla luetaan arvo merkkijonosta. Ero on se, että Parse aiheuttaa virheen, jos merkkijono ei ole sopivassa muodossa. TryParse käsitellään tämän osan seuraavassa jaksossa.

string merkkijono = "123,45";
float luku = float.Parse(merkkijono);
Console.WriteLine(luku);
123,45
Desimaalierotin

Merkkijonosta luettaessa desimaalierottimena käytetään oletuksena järjestelmässä määriteltyä erotinta. Yllä olevassa esimerkissä erotin on pilkku, ei piste. Konsolissa desimaalierotin näkyy myös pilkkuna.

Kun float-muuttuja luodaan suoraan koodissa (esimerkiksi float luku = 123.45f;), erottimena käytetään aina pistettä. Mutta jos haluat merkkijonon, jonka arvo on "123,45", käytä pilkkua.

Jos merkkijonon arvoksi annettaisiin pilkun sijaan piste, konsoliin tulisi virheilmoitus, kun sovellus ajetaan:

string merkkijono = "123.45";
float luku = float.Parse(merkkijono);
Console.WriteLine(luku);
Unhandled Exception: System.FormatException: Input string was not in a correct format.
   at System.Number.ParseSingle(...)
   at System.Single.Parse(String s)
   ...

Käyttäjän syötteen tarkistaminen

Ehtolauseilla voidaan tarkistaa myös käyttäjän syöte. Jos käyttäjältä kysytään lukua (int) ja hän kirjoittaakin tekstiä, halutaan tulostaa jokin viesti, esimerkiksi "Virheellinen syöte", sen sijaan että sovellus kaatuu virheeseen.

Tähän käytetään toimintoa x.TryParse(string, out t), jossa x ja t ovat tietotyyppejä. Sana out tarkoittaa, että arvo tallennetaan muuttujaan, jos muunnos onnistuu.

Muista tämä

Tätä käytetään jatko-osioissa paljon.

string syöte;   // string-muuttuja käyttäjän syötettä varten

Console.Write("Anna luku: ");
syöte = Console.ReadLine();   // kysytään käyttäjältä syötettä

int luku;   // muuttuja sitä varten, jos syöte onkin luku

// Ehtolause toimii näin:
// 1) int.TryParse -> aloitetaan muunnosprosessi
// 2) syöte -> ensimmäinen parametri eli string-arvo, joka halutaan muuttaa
// 3) out -> tallennetaan lopputulos johonkin muuttujaan
// 4) luku -> muunnos tallennetaan luku-muuttujaan, JOS se onnistuu
// Eli: jos käyttäjä on antanut kokonaisluvun, muunnos tallennetaan luku-muuttujaan
if (int.TryParse(syöte, out luku))
{
    Console.WriteLine("Syötteeksi annettiin integer luku!");
}
// Jos käyttäjä EI ole antanut kokonaislukua, siirrytään else-ehtoon
else
{
    Console.WriteLine("Syötteeksi annettiin jotakin muuta kuin integer..");
}

Jos syötteeksi annetaan kokonaisluku:

Anna luku: 10
Syötteeksi annettiin integer luku!

Jos syötteeksi annetaan jotain muuta:

Anna luku: asd
Syötteeksi annettiin jotakin muuta kuin integer..

Käyttäjän syötteen tarkistaminen silmukan sisällä

Syötteen voi tarkistaa myös silmukan sisällä. Tässä yhdistetään edellisen jakson int.TryParse-toiminto ja while-silmukka.

Käyttäjältä kysytään ikää niin kauan, kunnes hän syöttää kokonaisluvun eli int-arvon.

Tämä kannattaa muistaa

Silmukka, joka kysyy syötettä uudelleen kunnes se on kelvollinen, on yleinen tapa tarkistaa käyttäjän antamat tiedot.

string syöte;   // muuttuja syötettä varten
int ikä;        // muuttuja ikää varten

// Ikuinen silmukka
while (true)
{
    // kysytään käyttäjältä ikä
    Console.Write("Anna ikäsi: ");

    syöte = Console.ReadLine();

    // Tarkistetaan, antoiko käyttäjä syötteeksi PELKÄSTÄÄN kokonaisluvun
    if (int.TryParse(syöte, out ikä))
    {
        // jos antoi, tulostetaan käyttäjän ikä ja poistutaan silmukasta
        Console.WriteLine("Olet " + ikä + " vuotta vanha!");
        break;
    }
    else
    {
        // Jos käyttäjä ei antanut kokonaislukua, kysytään sitä uudestaan
        Console.WriteLine("Et syöttänyt kokonaislukua.. yritäppä uudelleen");
        Console.WriteLine();
    }
}
Anna ikäsi: En anna
Et syöttänyt kokonaislukua.. yritäppä uudelleen

Anna ikäsi: En jaksa
Et syöttänyt kokonaislukua.. yritäppä uudelleen

Anna ikäsi: Miks..
Et syöttänyt kokonaislukua.. yritäppä uudelleen

Anna ikäsi: 20
Olet 20 vuotta vanha!
