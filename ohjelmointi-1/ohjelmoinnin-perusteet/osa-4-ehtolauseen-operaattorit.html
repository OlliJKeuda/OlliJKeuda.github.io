Osa 4: Ehtolauseen operaattorit

Vertailuoperaattoreilla ja JA- ja TAI-ehdoilla rakennat ehtoja, joiden perusteella ohjelma valitsee, mitä koodia ajetaan.

Vertailuoperaattorit

if-lauseeseen lisätään ehto, jossa arvoja vertaillaan operaattoreilla.

OperaattoriTarkoitus
==yhtäsuuri kuin (arvot ovat samat)
!=ei yhtäsuuri kuin
>suurempi kuin
<pienempi kuin
>=suurempi tai yhtäsuuri kuin
<=pienempi tai yhtäsuuri kuin

Yhtäsuuri kuin (==)

Tarkistetaan, ovatko annetut arvot yhtäsuuria eli samoja, lisäämällä arvojen väliin kaksi yhtä kuin -merkkiä ==.

string merkkijono = "Omena";

if (merkkijono == "Omena")
{
    Console.WriteLine("Merkkijono on Omena");
}

int luku = 10;

if (luku == 10)
{
    Console.WriteLine("Luku on yhtäsuuri kuin 10");
}
Merkkijono on Omena
Luku on yhtäsuuri kuin 10

Suurempi ja pienempi kuin

Kun halutaan verrata, onko luku suurempi tai pienempi kuin toinen luku, käytetään merkkejä > ja <.

int luku = 5;

if (luku > 10)
{
    Console.WriteLine("Luku on suurempi kuin 10");
}
else if (luku < 10)
{
    Console.WriteLine("Luku on pienempi kuin 10");
}
Luku on pienempi kuin 10

Näiden perään voidaan lisätä myös =-merkki. Silloin tarkistetaan, onko luku suurempi tai yhtäsuuri kuin (>=) tai pienempi tai yhtäsuuri kuin (<=) annettu luku:

int luku = 10;

if (luku >= 10)
{
    Console.WriteLine("Luku on suurempi tai yhtäsuuri kuin 10");
}
Luku on suurempi tai yhtäsuuri kuin 10

Ei yhtäsuuri kuin (!=)

Voidaan myös tarkistaa, onko annettu arvo ei yhtäsuuri kuin toinen arvo.

int luku = 10;

if (luku != 10)
{
    Console.WriteLine("Luku EI ole yhtäsuuri kuin 10");
}

Tässä esimerkissä luku on 10, joten ehto ei toteudu eikä konsoliin tulosteta mitään.

JA- ja TAI-operaattorit

JA-operaattori (AND)

Ehtoihin voidaan lisätä useita tarkistuksia, jolloin ehto voidaan määritellä laajemmin. if- ja else if -ehtoihin lisätään useita määrittelyjä kahdella &-merkillä && (näppäinyhdistelmä Shift + 6). Ehto toteutuu vain, jos kaikki tarkistukset toteutuvat.

string nimi = "Pekka";
int ikä = 20;

if (nimi == "Pekka" && ikä < 18)
{
    // JOS nimi-muuttujan arvo on "Pekka"
    // JA ikä-muuttujan arvo on alle 18
    // niin tämä ehto toteutuu
    Console.WriteLine("Pekka on alaikäinen");
}
else if (nimi == "Pekka" && ikä >= 18)
{
    // JOS nimi-muuttujan arvo on "Pekka"
    // JA ikä-muuttujan arvo on suurempi tai yhtäsuuri kuin 18
    // niin tämä ehto toteutuu
    Console.WriteLine("Pekka on aikuinen");
}
Pekka on aikuinen

TAI-operaattori (OR)

if-else-lauseeseen voidaan määrittää myös vaihtoehtoisia ehtoja, joista jokin riittää ehdon toteutumiseen. Tämä lisätään kahdella pystyviivalla || (pikanäppäin Alt Gr + <). Ehto toteutuu, jos jokin tarkistuksista toteutuu.

int arvosana = 4;   // integer-muuttuja

if (arvosana == 0)
{
    // Jos arvosana on 0, niin hylätty
    Console.WriteLine("Hylätty");
}
else if (arvosana == 1 || arvosana == 2)
{
    // Jos arvosana on 1 TAI 2, niin tyydyttävä
    Console.WriteLine("Tyydyttävä");
}
else if (arvosana == 3 || arvosana == 4)
{
    // Jos arvosana on 3 TAI 4, niin hyvä
    Console.WriteLine("Hyvä");
}
else if (arvosana == 5)
{
    // Jos arvosana on 5, niin kiitettävä
    Console.WriteLine("Kiitettävä");
}
else
{
    // Jos annettu arvosana ei ole 0-5 väliltä, tämä ehto toteutuu
    Console.WriteLine("Ei mahdollinen arvosana..");
}
Hyvä
